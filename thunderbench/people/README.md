# ThunderBench: the people track

Does Thunder help people understand and change software faster and more accurately? Only people can answer that,
so this track is a study kit, run the same way every time. **No result is claimed until a round is recorded here.**

## The kit

- [sheet-thunder.md](sheet-thunder.md) and [sheet-python.md](sheet-python.md): the six programs and their 26
  questions, one sheet per language. The questions are the same; only the program text differs.
- [answers.md](answers.md): the answer key, computed by running both versions of every program
  (`node thunderbench/run.mjs` writes all three files).

## How a round runs

Follow [Testing Thunder with people who did not build it](../../docs/user-testing.md) for who takes part, consent,
and what the facilitator may say. For ThunderBench:

1. **Groups.** Each person reads half the programs in Thunder and the other half in Python, alternating which
   language comes first, so neither language always gets the easier programs or the tired reader.
2. **No running, no help.** Answer from the page alone. Note the start and finish time of each program.
3. **Score.** A "what does it give" answer is right when it means the same as the key (`30` and `$30` are both
   right). A "which line changes" answer is right when it names the key's line.
4. **Record** each round below: date, who took part (by group, never by name), and per language: accuracy and
   median time per program. Keep every round, including ones where Python does better.
