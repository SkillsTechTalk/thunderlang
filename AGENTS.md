## Usability and interaction design

Before designing or changing a user-facing feature, read [the design standard](./DESIGN.md).
Apply it alongside existing product-specific visual guidance and repository constraints.

- Start with the user's goal and a simple, truthful mental model. Use names that explain the task.
- Make the main action obvious and the result explicit, including why an answer or decision is right, wrong, or partially supported.
- Keep feedback accessible and visually restrained. Check every affected web, mobile, desktop, or extension surface.
- Complete the design checklist and short review record. State what was actually tested and any remaining usability gaps.
